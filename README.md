Croptopia Handbook is an up-to-date Patchouli-style book for new Croptopia versions. This guide mostly follows the format of the original book, but adds new recipes, ingredients, crops and trees from more recent versions.

## Features
- Support for opening the original Croptopia book. Just craft it and right-click to open.
- Support for both NeoForge and Fabric versions.
- No external download dependencies.
- All dessert recipes.
- All drink recipes.
- All ingredient recipes.
- All cooking recipes.
- All meal recipes.
- All snack recipes.
- All utensil recipes.
- All plant and tree information.
  - Includes biome locations, supporting modded biomes as well.

This mod uses a fork of Patchouli for modern Minecraft versions called
Handbook. The Handbook mod is updated frequently and comes out with each Minecraft
release. It is a separate mod, as this is outside of what would
reasonably be expected for the Croptopia dev to migrate to. If in the future
they do, then this mod will no longer be needed. It is not a requirement to download and
install the Handbook mod, as it is bundled with this mod.
