This is to provide a guide for Croptopia. Croptopia dev does an excellent job
of keeping up with the latest Minecraft versions. Croptopia uses the excellent
Patchouli for a guidebook. Problem is that Patchouli is extremely slow to
update, as it really only gets updated when Quark or Botania get updated.

This mod uses a fork of Patchouli for modern Minecraft versions called
Handbook. Handbook is updated frequently and comes out with each newer
Minecraft release. It is a separate mod, as this is outside of what would
reasonably be expected for the Croptopia dev to migrate to. If in the future
they do, then this mod will no longer be needed.
